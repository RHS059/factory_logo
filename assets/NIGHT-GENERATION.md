# Night artwork

Tool: built-in image generator. Five separate lighting-weather edits, one for each active painted layer. All outputs retain RGBA transparency and the 1678 × 937 reference canvas. No color filter substitutes for the generated images.

## assets/clouds-night.png

Input: assets/clouds-v3.png

Prompt:

Use case: lighting-weather. Edit target: the supplied transparent clouds landscape layer. Make a NIGHT version for a layered 3D painted landscape. Preserve the exact full-canvas placement, silhouettes, scale, brush texture and alpha transparency. Do not crop, zoom, move objects, fill transparent areas or add scenery. Change only the illumination and palette: rich midnight blue and violet, gentle lavender moonlight, sparse cyan edge highlights. Remove all warm yellow/orange daylight. Keep forms visible and painterly, with dark blue shadows. Transparent background is essential, not black. No text, stars, moon, new objects, or border. Match the input aspect ratio and layout exactly.
